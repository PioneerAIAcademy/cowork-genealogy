# CLA signers

Everyone who contributes to this project signs the
[Contributor License Agreement](./CLA.md) — outside contributors and
team members alike.

## How to sign

Add one row to the table below, in a pull request **from your own GitHub
account**. Nobody can sign for you.

**Put the row in the same pull request as your contribution.** There is
no separate signing step to wait on. If you would rather sign before you
start work, a standalone pull request is fine too.

In the pull request description, include this line:

> I have read and agree to the Contributor License Agreement at the
> version recorded in my row.

Read [CLA.md](./CLA.md) first, in full. Use your full legal name, not a
nickname or handle, and put your row at the bottom. You do this once —
later pull requests need nothing.

Record the **Version** from the header of `CLA.md` as it stands the day
you sign. That column is what makes this record hold up: it says which
text you agreed to, so a later revision cannot change what you signed.

Email addresses are deliberately not collected here. This is a public
repository, and a plaintext list of contributors' email addresses is a
scrape target. The identity binding comes from your signing commit —
its author email, timestamp, and GitHub account are permanent in this
repository's history.

**Row format:**

| Full legal name | GitHub | Date signed | Version |
|---|---|---|---|
| Ada Lovelace | `@adalovelace` | 2026-09-02 | 1.0 |

The example is illustrative. Do not copy it into the table.

## For maintainers

**Do not merge a contribution until its author has a row here** — added
in that pull request or an earlier one. This is the only gate on outside
contributions; nothing else will catch a missing signature.

**When the CLA changes.** Publish the new version with a new version
number in `CLA.md`'s header, then ask current signers to add a fresh row.
Never edit or remove an existing row — it is the record of what that
person agreed to and when. A person's most recent row is what binds them.

**When someone leaves.** Their row stays. It records a grant of rights in
work that is still in the project.

Team members sign this **and** the [Team Agreement](./TEAM-AGREEMENT.md);
see [TEAM-SIGNERS.md](./TEAM-SIGNERS.md).
