# england-census-timeline

A minimal non-US scenario: one person, all facts in England.

**Subject:** William Ashford, b. ~1838 Canterbury, Kent, England; d. 1874 Canterbury. Documented facts: birth (~1838), 1851 census residence, marriage (1859), death (1874), each linked to him. All persons are deceased.

Only the 1851 census is documented, so he is alive and resident in England across the 1841, 1861 and 1871 English decennial censuses with no record of them, none of which is a US federal census year. Kept small (one person, four facts) so the census years a timeline expects for him can be checked exactly.
