# dutch-mother-name-disputed

A mid-research project where the user disputes an OCR reading of a mother's
name. The birth act reads "Jannetje [?] van Noord" (OCR uncertain), but the
ten-year marriage index from a different record reads "Fannetje van Noord" —
agreeing with the user who sees "Tannetje van Noord" on the image. The dispute
is already recorded as c_001 (unresolved, a_002 vs a_003, no analysis yet).

Used by `user-disputes-ocr-reading.json` in the conflict-resolution suite.
