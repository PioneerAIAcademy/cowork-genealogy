# empty-project-two-fact-objective

`empty-project-just-created` with an objective that holds **two independent
facts**: where Patrick Flynn is buried, and whom he married. Everything else is
identical: one stub person, no questions, no plans, no log, no evidence.

- **Objective:** Find where Patrick Flynn (b. ~1845, d. 1908) is buried, and
  whom he married
- **Questions:** none
- **GedcomX persons:** I1 (Patrick Flynn — stub, name only, no facts)

## Used by

- `question-selection` (`two-fact-objective-asks-first.json`): given two
  independent facts and no question yet, the agent writes nothing and asks the
  researcher which to research first (step mode, section E).
