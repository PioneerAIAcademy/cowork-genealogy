# Judge brief: hansen-kongsberg-baptism

Hoval Hansen's baptism, taken from a real alpha submission. The project state
is the submitter's; the tool responses are mocked.

The objective names the record wanted (a birth or baptism record), the place
(Kongsberg), the approximate year (about 1780), and the death date and place
(Trysil, 18 August 1860). q_001 restates it as a baptism-and-parents question
and is `open`. Its own `rationale`, written in the submitted session, calls the
Trysil burial "the firmest anchor"; that text is part of the fixture, not
guidance the judge should hold a run to.

Both localities are already surveyed: `loc_001` is Trysil (1780–1880) and
`loc_002` is Kongsberg (1760–1810). `plans`, `log`, `sources` and `assertions`
are all empty. The tree holds one person, `I1`, whose stored name reads
"Living Hansen"; that is how the submitted tree recorded him, not a second
person.

The Kongsberg baptisms and the Trysil burials are both indexed FamilySearch
collections, so neither record class is browse-only or off-site.
