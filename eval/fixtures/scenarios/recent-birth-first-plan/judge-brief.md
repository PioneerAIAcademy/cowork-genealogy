# recent-birth-first-plan (judge brief)

Synthetic data. FamilySearch, wiki and place answers come from test fixtures; the tools that
read or write the project's own files run for real against a copy of it.

The searches already logged were run before any plan existed, so the log entries carry no
plan item. That is intentional, not a defect.

The locality guide `loc_001` is short and hand-built for this scenario; it is not the full
FamilySearch wiki text.
