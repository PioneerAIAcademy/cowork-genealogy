## What the skill must do

Lancaster County, scores within 0.03 of each other — his own entries cannot be told
apart. His mother and stepfather are known, so the lever is to search the household
by a co-resident: Catharina (or Jacob) Kessler as the principal. That search returns
the Kessler household, which enumerates Henry Weber, 8 — the same persona as one of
the six — and confirms which entry is the subject.
