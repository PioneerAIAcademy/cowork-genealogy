# census-brannon-family

A just-created project for **Ellen Brannon** (b. about 1870), built from the
`person-read-brannon` MCP fixture. Persons are keyed by their FamilySearch ids
(Ellen is `BRNN-MOM`).

The tree holds Ellen, her husband, and three children, all biological children
of both: James (b. 1892), Catherine (b. 1895) and Thomas (b. 1904). No child has
a death date. `research.json` holds only the project header and researcher
profile: no sources, assertions or questions yet.

Used by the check-warnings census test (`ut_check_warnings_022`). The 1900 and
1910 census fertility counts arrive only in the request; nothing in the project
records them.
