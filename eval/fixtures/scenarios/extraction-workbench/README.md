# extraction-workbench

A freshly created project whose objective names no person: the researcher hands
records in one at a time to be extracted. No questions, plans, log, sources,
assertions or tree persons.

## Used by

- `extraction-append` tests. Each extracts an unrelated record (Becker, Ferber,
  Flynn), so a project objective naming one person reads to the judge as a
  mismatch with every other record. This scenario has no such objective.
