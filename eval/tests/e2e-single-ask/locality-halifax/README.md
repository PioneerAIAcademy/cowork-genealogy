# locality-halifax

**Ask:** "Please write a locality guide for Halifax, Nova Scotia, Canada, for about 1836 to 1900, covering the marriage, vital, census and church records available, and save it to the project."

**Expected owner:** `locality-guide`. **Expected save:** a new `localities` entry whose guide carries every
heading of the locality-guide template. **Required:** `locality_survey`.

## Where it came from

Issue #4602 item 1, the real-input check: one of the four places PR #4598 measured, each a one-turn ask
into the starting project of the e2e fixture `patrick-hoban-spouse`. The unit fixtures answer each survey call with
500 to 2,500 characters; real pages run to 40,000 a part. This runs the agent on the live survey.
